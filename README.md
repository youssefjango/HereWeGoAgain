**Light out of Memory Again** is a game made using Nvidia's branch of UE 5.6. 
All the Static Meshes used come from Fab assets along most of the animations.

Summary:

A patient in a futuristic hospital is seeking help with memory issues specifically from his childhood. In this world, people no longer die, as there is no more wars and advanced medical treatments for any disease very accessible. However, people are still losing their childhood memories like this patient, Smith, as time goes. Fortunately,  there is a device that solves these issues by re-experiencing those memories he had playing games from the 21st that impacted his childhood. He must play again and beat the levels using some of the nostalgic game mechanics that impacted his childhood. 

Controls:

WASD for moving

x for pausing

Right-click for a special retro control in each level

Additional retro levels are expected to be added in the future.
